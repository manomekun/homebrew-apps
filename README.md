# homebrew-apps

個人開発アプリ用の Homebrew tap。

## セットアップ

```bash
brew tap manomekun/apps
```

## インストール

```bash
brew install manomekun/apps/tubesaver
brew install manomekun/apps/imechen
```

## アプリ一覧

| アプリ | 説明 |
|--------|------|
| [TubeSaver](https://github.com/manomekun/yt-dlp-ui) | yt-dlp を使った動画ダウンローダー |
| [imechen](https://github.com/manomekun/imechen) | オフライン画像/動画コンバーター・圧縮ツール |
